# 🔐 SafeBox — Smart Password Generator

**SafeBox** is a sleek, responsive, and theme-adaptive password generator built with pure **HTML, CSS, and JavaScript** — no backend required.  
It lets users generate secure passwords, assess their strength, copy them instantly, and save them locally with labels using browser storage.

---

## 🌟 Features

✅ **Generate Secure Passwords** — choose uppercase, lowercase, numbers, and symbols.  
✅ **Adjustable Length** — select password length from 4 to 20 characters.  
✅ **Password Strength Indicator** — color-coded feedback on strength.  
✅ **Copy to Clipboard** — one-click copy functionality.  
✅ **Local Saving (No Backend)** — store generated passwords with labels in `localStorage`.  
✅ **Edit, Reveal, Delete, or Clear All** saved passwords.  
✅ **Light / Dark Theme** — auto-detects system theme, toggle manually anytime.  
✅ **Fully Responsive** — optimized for mobile, tablet, and desktop.  
✅ **Dynamic Footer** — copyright year updates automatically.
